Privacy policy

Last updated: 30 October 2026

Who this covers

ew Workspace Bridge is a personal tool operated by a single individual on their own computer. The only Google account it is ever authorised for is the owner's own account.

What data is accessed

With the owner's explicit consent, the application can read email messages and attachments, read files stored in Google Drive, and create or send messages on the owner's behalf. Access is requested only through Google's OAuth 2.0 flow, and only for the scopes the owner approves.

Where data goes

Nowhere. Data is processed locally on the owner's machine and is only sent to Google's own APIs in order to perform the requested action. There is no analytics, no tracking, no advertising, and no third-party service involved.

Storage and retention

OAuth credentials are stored in a local file on the owner's computer, readable only by the owner's operating-system user. Email and file content is not copied to any server, database or cloud storage operated by this application, because none exists. Anything held in memory during a session is discarded when the session ends.

Sharing

No data is sold, rented, transferred or disclosed to any third party. No data is used to train machine-learning models.

Your control

The owner can revoke the application's access at any time from Google Account permissions, and can delete the local credential file. Revoking access stops all use immediately.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
